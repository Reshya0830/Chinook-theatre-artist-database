🎭 Chinook Theatre Artists Database

The Chinook Theatre Artists Database is a SQL-based project designed to efficiently manage and analyze theatre-related data, including artists, plays, acts, audiences, and ticket sales. This project uses SQL queries such as JOIN, GROUP BY, and HAVING to explore artist performances, identify top genres, and generate insights on audience engagement.

Key Features:

Manage and organize theatre artists, plays, and acts in a relational database.

Retrieve, filter, and aggregate data using advanced SQL commands.

Analyze ticket sales and audience data to identify top-performing genres and artists.

Gain insights into performance duration, popularity, and trends.

Tools & Technologies:

SQL (SELECT, JOIN, GROUP BY, HAVING, ORDER BY)

Database Management and Query Optimization

Data Analysis and Reporting
